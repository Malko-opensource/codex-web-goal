# Codex Web Goal

This is a new, independent project. Do not import implementation from its parent directory.
Use TypeScript and test observable protocol behavior. Run `npm test`, `npm run build`, and
`npm run test:browser` after behavior changes. Never use a person's real ChatGPT chat in tests
without their explicit authorization. Synthetic browser fixtures and fake App Servers are the default.

The native Codex goal owns objectives and completion. The bridge owns delivery, leases and evidence.
Never access ChatGPT cookies or undocumented backend APIs. All browser automation is visible DOM interaction.
The remote file tools have a real workspace boundary; they do not inherit Codex's sandbox.
Preserve terminal dispatch uncertainty rather than resending an ambiguous browser submission.
Do not publish packages, extensions or Git remotes as part of a local build.
